# Equipo-A
Repositorio creado por Eduardo

Juego: The Timegeon, un juego donde cada uno de los protagonistas buscar alcanzar el final de una mazmorra donde cada piso cambia de era y el primer piso puede ser el viejo oeste o un futuro lejano con enemigos y habitaciones tematicas

Equipo: Antonio, Alejandro, Sergio, Rafa, Eduardo

Como colaborar: Cada uno iremos nos encargaremos de algo diferente segun nuestra especialidad e iremos coordinando lo que nos falta con un canal de mensajeria de discord
